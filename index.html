    기기 간 동기화

    내 GitHub의 비공개 저장소에 기록을 저장해서 PC와 폰이 같은 기록을 보게 해요. 토큰은 이 기기의 브라우저에만 저장돼요.

    토큰 만드는 방법
    1. GitHub 토큰 만들기 페이지를 열어요.
    2. 이름은 아무거나, 만료일은 1년으로 해요.
    3. Repository access에서 “Only select repositories”를 고르고 위 저장소를 선택해요.
    4. Permissions → Repository permissions → Contents를 “Read and write”로 바꿔요.
    5. Generate token을 누른 뒤 나온 github_pat_… 값을 복사해서 위 칸에 붙여넣어요.
